# phpnitro/ui

The [PhpNitro](https://github.com/phpnitro/phpnitro) framework's UI package — the native render engine widgets (`Engine\Native\*`: layout, Canvas draw commands, animations, gestures) and core drawing primitives.

This package is a read-only mirror, extracted from the main [phpnitro/phpnitro](https://github.com/phpnitro/phpnitro) monorepo — contribute there, not here.

## Installation

```bash
composer require phpnitro/ui
```
